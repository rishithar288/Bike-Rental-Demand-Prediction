# Bike Rental Demand Prediction

## Project Overview

This project predicts bike rental demand using Machine Learning and Python.

The project uses historical bike rental data and regression techniques to predict the number of bike rentals based on different input features.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
- Machine Learning
- Regression

## Project Files

- `Bike_Rental_Project (1).ipynb` – Complete machine learning project notebook
- `Dataset .csv` – Dataset used for training and analysis
- `app.py` – Application code for making predictions
- `bike_rental_model-2.pkl` – Trained machine learning model
- `bike_rental_encoder.pkl` – Saved encoder used for preprocessing

## Machine Learning Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Encoding
5. Model Training
6. Model Evaluation
7. Model Saving
8. Prediction

## Project Objective

The main objective of this project is to build a machine learning model that can predict bike rental demand from available input features.

## How It Works

The dataset is first cleaned and preprocessed. Categorical features are encoded and the processed data is given to a regression model.

The trained model is saved as a `.pkl` file and can be used by the application to generate predictions.
